## 项目一句话

Packrun 是一个自建的 **Go 中控服务 + 浏览器控制台**：中控机纳管多台业务服务器，
用户在浏览器里完成「选服务器 → 选目录 → 上传 zip/jar → 绑定脚本 → 执行 → 查看回执」
的完整部署链路，执行通道支持本地沙箱与 SSH 两种模式。

## 快速开始

后端（默认 `deploy.mode=ssh`，本地开发可覆盖为 `local`）：

```bash
cd server
go run ./cmd/packrund -config configs/config.yaml
# 监听 0.0.0.0:9000，默认访问 http://localhost:9000/packrun/
# PACKRUN_DEPLOY_MODE=local go run ./cmd/packrund -config configs/config.yaml
```

前端：

```bash
cd web
pnpm install
pnpm dev
# http://localhost:5173 ，/api 与 /healthz 已代理到 127.0.0.1:9000
```

首次启动（空数据库、`server.mode=debug`）会创建：

| 账号 | 口令 | 角色 |
|---|---|---|
| `admin` | `Admin@12345` | 管理员 |
| `auditor` | `Audit@12345` | 审计员（仅 debug 模式创建） |

生产环境必须通过 `PACKRUN_JWT_SECRET`（≥32 字符）与 `PACKRUN_ADMIN_PASSWORD`
提供密钥与管理员口令，否则服务拒绝启动。详见 [09-构建运行与运维](09-构建运行与运维.md)。

## 文档约定

- 源码路径均相对于仓库根目录；文档内的相对链接指向真实文件。
- 配置默认值以 [config.go](../../server/internal/config/config.go) 与
  [config.yaml](../../server/configs/config.yaml) 为准。
- 文中「生产环境」指服务器 `env=prod` 的部署目标，与 `server.mode=release` 的运行模式
  是两个不同维度，注意区分。
