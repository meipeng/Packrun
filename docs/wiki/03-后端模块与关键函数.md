# 03 后端模块与关键函数

本文按 Go 包说明职责、关键类型与函数。数据表字段与状态机见

## 1. `cmd/packrund`：进程入口

文件：[main.go](../../server/cmd/packrund/main.go)

职责：装配配置、存储、执行器、路由与 HTTP 服务。

| 步骤 | 代码 | 说明 |
|---|---|---|
| 解析参数 | `flag.String("config", "configs/config.yaml", ...)` | 支持 `-config` 指定 YAML |
| 加载配置 | `config.Load` | 默认值 → YAML → 环境变量 |
| 安全校验 | `cfg.Validate` | 失败直接 `log.Fatalf`，服务不启动 |
| 打开存储 | `store.Open` | 建目录、开 SQLite、迁移 |
| 初始化 | `store.Seed` | 管理员/演示数据 |
| 中断收口 | `api.RecoverInterruptedTasks` | 重启后清理未完成任务 |
| 执行器 | `deploy.SSHDeployer` / `deploy.LocalDeployer` | 按 `deploy.mode` 选择 |
| 应用 | `api.NewApp` | 并发闸门、可信代理、取消登记 |
| 指标采集 | `api.StartMetricWorker` | 仅 SSH 模式 |
| 路由 | `api.NewRouter` + `api.WithBasePath` | 子路径挂载 |
| HTTP | `http.Server` | 固定超时与 1 MiB 头部上限 |

## 2. `internal/config`：配置

文件：[config.go](../../server/internal/config/config.go)

### 2.1 配置结构

| 结构 | 字段 | 说明 |
|---|---|---|
| `Config` | `Server` / `Auth` / `Storage` / `Deploy` / `Bootstrap` | 全部可调参数 |
| `ServerConfig` | `Addr` / `Mode` / `BasePath` / `AllowedOrigins` / `TrustedProxies` | 监听、Gin 模式、子路径、CORS、可信代理 |
| `AuthConfig` | `JWTSecret` / `TokenTTLMinute` / `OTPIssuer` / `OTPPeriod` / `OTPSkew` | JWT 与 TOTP |
| `StorageConfig` | `DBPath` / `PackageDir` / `SandboxRoot` / `MaxTotalMB` | 数据路径与包仓库配额 |
| `DeployConfig` | `Mode` / `MaxConcurrent` / `StepDelayMS` / `MaxPendingPerUser` / `MetricsIntervalSec` / `AutoTrustHostKey` | 执行器与资源限制 |
| `BootstrapConfig` | `AdminUsername` / `AdminPassword` | 首次初始化管理员 |

### 2.2 关键函数

| 函数 | 行为 |
|---|---|
| `defaults()` | 内置默认值：`0.0.0.0:9000`、`debug`、`base_path=/packrun`、`deploy.mode=ssh`、并发 3、步骤延迟 350ms、单用户 10、指标间隔 300s、TOFU 开启 |
| `Load(path)` | 先取默认值；文件不存在允许启动（全默认）；存在则 YAML 反序列化；最后 `applyEnv` |
| `applyEnv(cfg)` | 支持 `PACKRUN_ADDR`、`PACKRUN_BASE_PATH`、`PACKRUN_JWT_SECRET`、`PACKRUN_DEPLOY_MODE`、`PACKRUN_ADMIN_PASSWORD`、`PACKRUN_MAX_CONCURRENT` |
| `Validate()` | 校验 `server.mode`（debug/release/test）、`deploy.mode`（local/ssh）、容量非负、子路径格式、单用户上限、指标间隔、可信代理；非 debug 模式强制安全项 |
| `normalizeBasePath(raw)` | 空或 `/` 归一为 `/`；必须以 `/` 开头；禁止 `..`；仅允许字母数字与 `-_.~/`；`path.Clean` |

非 `debug` 模式的启动硬约束：

- `auth.jwt_secret` 非空、非默认值、长度 ≥ 32；
- `bootstrap.admin_password` 非空且非默认 `Admin@12345`；
- `server.allowed_origins` 不允许 `*`；
- `deploy.mode=ssh` 时禁止 `PACKRUN_SSH_INSECURE=1`。

## 5. `internal/auth`：认证原语

文件：[auth.go](../../server/internal/auth/auth.go)

### 5.1 口令

| 函数 | 说明 |
|---|---|
| `HashPassword(raw)` | bcrypt `DefaultCost` |
| `VerifyPassword(hash, raw)` | bcrypt 比对 |

### 5.2 JWT

| 函数 | 说明 |
|---|---|
| `IssueToken(secret, uid, username, role, tokenVersion, ttl)` | HS256，Issuer 固定 `packrun`，Claims 含 `uid/usr/rol/ver` 与标准时间声明 |
| `ParseToken(secret, token)` | 只接受 `HS256`，校验 Issuer；失败返回错误 |

`TokenVersion` 用于会话吊销：改密、调整角色/范围/状态时递增，旧令牌立即失效。

### 5.3 TOTP

| 函数 | 说明 |
|---|---|
| `GenerateSecret()` | 20 字节随机数，base32 无填充 |
| `OtpauthURL(issuer, account, secret, period)` | 生成 `otpauth://totp/...`，SHA1 / 6 位 / 指定周期 |
| `ValidateOTPCode(secret, code, at, period, skew)` | 允许 ±skew 个时间窗；命中返回时间步进 `counter`，供一次性消费 |
| `ValidateOTP(...)` | 只返回是否通过 |
| `GenerateOTP(secret, at, period)` | 生成指定时刻 6 位口令（测试/展示） |
| `hotp(secret, counter)` | RFC 4226 HOTP 实现（HMAC-SHA1 + 动态截断） |

### 5.4 恢复码

| 函数 | 说明 |
|---|---|
| `GenerateRecoveryCodes(n)` | 默认 10 枚，80-bit 随机，格式 `XXXX-XXXX-XXXX-XXXX` |
| `NormalizeRecoveryCode(code)` | 去空格/连字符并转大写 |
| `HashRecoveryCode(code)` | SHA256 十六进制摘要；恢复码熵足够，不使用慢哈希 |

## 6. `internal/deploy`：执行通道

### 6.1 抽象与公共类型

文件：[deployer.go](../../server/internal/deploy/deployer.go)

```go
type Deployer interface {
    Deploy(ctx context.Context, req Request) error
}

type Request struct {
    Server     model.Server
    Directory  model.Directory
    Package    model.Package
    PreScript  *model.Script
    Script     *model.Script
    SourcePath string
    Hooks      Hooks
}
```

`Hooks` 三个回调：

- `OnStep(name)`：开始一个新步骤；
- `OnLog(line)`：向当前步骤追加日志；
- `OnStage(stage, progress)`：更新任务阶段与进度。

步骤名称常量：`StepPrepare`、`StepPreCheck`、`StepBackup`、`StepUpload`、
`StepVerify`、`StepUnpack`、`StepScript`。

安全辅助函数：

| 函数 | 说明 |
|---|---|
| `ValidateServerName(name)` | 仅允许 `A-Za-z0-9._-`，长度 1-64，拒绝 `.` 与 `..` |
| `NormalizePath(p)` | 必须绝对路径；拒绝 `..`；拒绝根目录 `/`；返回 `filepath.Clean` 结果 |

### 6.2 本地沙箱执行器

文件：[local.go](../../server/internal/deploy/local.go)

`LocalDeployer{SandboxRoot, StepDelay}`，目标路径为
`<SandboxRoot>/<ServerName>/<去掉开头的部署路径>`，并校验不越界。

`Deploy` 流程：

1. `StepPrepare`：创建目标目录；统计目录占用，超过 `MaxSizeMB` 拒绝。
2. `StepPreCheck`：有前置脚本时仅渲染内容回显。
3. `StepBackup`：开启备份且目录非空时，`os.Rename(target, target.bak-<时间戳>)` 后重建空目录。
4. `StepUpload`：复制安装包到 `.incoming-<包名>`。
5. `StepVerify`：计算 SHA256 与 `Package.SHA256` 比对。
6. `StepUnpack`：zip 真实解压（安全校验）；jar 等单文件制品 `rename` 到目标；
   目标已存在且 `AllowOverwrite=false` 时拒绝。
7. `StepScript`：后置脚本仅渲染回显，**不实际执行**。
8. 清理超出 `KeepReleases` 的 `<target>.bak-*`；进度 100。

关键辅助：

| 函数 | 说明 |
|---|---|
| `unzip(src, target, maxBytes, maxEntries)` | 拒绝绝对路径、`..`、符号链接、越界父目录、已存在符号链接；逐文件限制累计字节；失败清理已写文件 |
| `checkUnpackedSize(req)` | 解压前按 zip 条目数与声明解压体积预检 |
| `unpackBudget(req)` | 上限来自 `Directory.MaxSizeMB`，未配置按 1GB；条目上限 20000 |
| `pruneBackups(target, keep)` | 按名称排序只保留最近 keep 个备份 |
| `dirSizeMB(path)` | 递归统计普通文件大小（向上取整 MB） |
| `copyFile(src, dst)` | 复制包文件 |

### 6.3 SSH 执行器

文件：[ssh.go](../../server/internal/deploy/ssh.go)

`SSHDeployer{StepDelay, KnownHosts, Insecure, AutoTrust, OnTrust}`。

`Deploy` 流程：

1. `NormalizePath` + `checkUnpackedSize` 预检。
2. `dial`：解析凭据引用，建立 SSH 连接；`remoteExec` 默认超时 15 分钟。
3. `StepPrepare`：`mkdir -p`；`du -sm` 检查目录占用阈值。
4. `StepPreCheck`：前置脚本（若绑定）在目标目录执行，失败即终止。
5. `StepBackup`：`BackupBeforeDeploy` 开启且目录非空时 `cp -a target target.bak-<时间戳>`。
6. `StepUpload`：上传到 `/tmp/packrun-<纳秒>-<安全文件名>`（`cat > remote`）。
7. `StepVerify`：`sha256sum` 比对。
8. `StepUnpack`：
   - zip：条目数限制；`unzip -Z1 | grep -Eq '(^/|\.\.)'` 检查越界路径；
     `zipinfo -l` 检查符号链接（目标机缺少 `zipinfo` 直接失败）；
     `ulimit -f` + `unzip -o -q`；解压后再次 `du -sm` 校验阈值。
   - jar 等：`AllowOverwrite=false` 时检查存在性，`mv -f` 替换。
9. `StepScript`：后置脚本以 base64 传输，`timeout <n> sh -c` 执行；
   `RunAs` 与登录用户不同时用 `sudo -n -u`。
10. 清理超出 `KeepReleases` 的远程备份；进度 100。

连接与信任：

| 函数 | 说明 |
|---|---|
| `dial(srv)` | `authType=password` 用 `ssh.Password`；否则 `ssh.ParsePrivateKey`；10 秒连接超时 |
| `hostKeyCallbackFor(srv)` | 已登记指纹 → 严格比对；未登记且 TOFU → 回调 `OnTrust` 异步落库；否则回退 `known_hosts` |
| `knownHostsCallback()` | 加载 `~/.ssh/known_hosts`；文件缺失时拒绝连接而非静默信任 |
| `ProbeHostKey(ctx, srv)` | 只握手不认证，采集当前主机公钥并返回算法、SHA256 指纹、是否已登记、是否匹配 |
| `ResolveCredential(ref)` | 仅支持 `env:NAME` 与 `file:/path`（支持 `~/`） |
| `InspectCredential(ref, authType)` | 凭据自检；key 类型额外验证私钥可解析且无 passphrase |
| `remoteExec.run(ctx, cmd)` | 单会话执行，支持上下文取消与超时；超时/取消发送 `SIGKILL` |
| `remoteExec.upload(ctx, local, remote)` | 以 `session.Stdin` 流式 `cat > remote` |
| `shellQuote(s)` | 单引号包裹并转义内部单引号 |
| `sanitizeName(name)` | 取 basename，空格替换为下划线 |

### 6.4 指标与连通性

文件：[metrics.go](../../server/internal/deploy/metrics.go)、[ping.go](../../server/internal/deploy/ping.go)、[hash.go](../../server/internal/deploy/hash.go)

| 类型/函数 | 说明 |
|---|---|
| `Prober` 接口 | `Probe(ctx, srv, dirs) (*model.ServerMetric, error)` |
| `SSHDeployer.Probe` | 一次远程 exec 采集 hostname、OS、uptime、核数、loadavg、内存、各目录 `df -kP` |
| `LocalDeployer.Probe` | 返回在线占位快照（不采集真实指标） |
| `buildMetricsCommand(dirs)` | 生成带 `PRHOST=` / `PROS=` / `PRUP=` / `PRCORES=` / `PRLOAD=` / `PRMEM=` / `PRDF ` 前缀的 POSIX sh 命令；根目录 `/` 始终采集 |

| `fileSHA256(path)` | 本地文件 SHA256 |

### 7.6 登录与会话相关处理器

| 函数 | 关键行为 |
|---|---|
| `login` | 账号与 IP 双维度失败计数；账号不存在也执行一次 bcrypt（防时序枚举）；口令错误统一提示；已绑定 OTP 时必须校验 TOTP 或恢复码；成功后签发 JWT、更新 `lastLoginAt`、写审计 |

| `consumeRecoveryCode` | 原子消费未使用恢复码 |

### 7.7 任务相关处理器

| 函数 | 关键行为 |
|---|---|
| `createTask` | 审计员拒绝；服务器/目录/包/脚本校验；目录必须属于服务器；脚本阶段匹配；`env=prod` 必须 step-up；单用户待执行配额；落库 `pending` 后异步执行 |
| `newTaskNo()` | `D` + `YYYYMMDDHHMMSS` + 6 位随机十六进制 |
| `runTask(id)` | 目录锁 → 服务器闸门 → 全局闸门 → 重读任务 → 上下文与取消登记 → 重载目录/包/脚本并校验目录快照 → 执行器 → 收尾 |
| `finishTask` | 更新终态、`finishedAt`；成功补 `progress=100`、`stage=done`；写 `task.finish` 审计；项目任务触发批次结算 |
| `listTasks` | 分页；按数据范围过滤；支持 `status` / `serverId` / `projectId` / `batchNo` / `keyword` |
| `getTask` | 单任务 + 步骤；校验服务器数据范围 |
| `cancelTask` | 审计员拒绝；范围校验；终态拒绝；`pending` 直接取消；运行中通过 `Sessions.cancel` 触发上下文取消 |
| `overview` | 统计服务器总数/在线数、今日任务/失败/运行中、最近 6 条任务、包总数、执行模式、服务器指标摘要 |
| `RecoverInterruptedTasks` | 启动时把未终态任务与运行中步骤标记失败，写 `task.recover` 审计，返回处理数量 |
